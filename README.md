# Connect4

Ce projet a été réalisé lors de ma dernière année de licence Double Diplôme Droit Informatique et consiste en un jeu puissance 4 ou connect4 en anglais. 

Le code présente quelques bugs légers et il n'est pas possible de le faire fonctionner puisque la base de données utilisée est locale et donc malheureusement inaccessible.

Le projet est codé en langage Java et utilise une base de donnée locale crée avec l'outil PGAdmin4.

Les commandes à utiliser pour faire fonctionner (sans la base) le projet sont les suivantes : 
javac -cp "lib/*" -d bin src/*.java => Pour compiler le projet.
java -cp "bin;lib/*" Main => Pour exécuter le projet.
